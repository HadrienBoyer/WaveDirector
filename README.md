# Wave Director - Enemy AI and Boss Rush Wave Spawner Tools

Version 1.1.0 (2026-03-01)

This Unity package lets designers build, preview, and balance enemy waves inside Unity with zero code.

## Features

- **ScriptableObject Timeline**: WaveTimelineConfig stores events per wave
- **Wave Timeline Editor Window**: Drag & drop prefabs onto a grid timeline
- **Runtime WaveDirector**: Supports difficulty modes (Aggressive / Balanced / Adaptive)
- **Performance-Friendly Spawning**: Pooling + coroutine pacing
- **Flexible Wave Completion**: Timer / kill-count / objective triggers
- **Save + Analytics Logging**: JSON / JSONL formats
- **Clean Extension Points**: Interfaces for enemies, player metrics, rewards
